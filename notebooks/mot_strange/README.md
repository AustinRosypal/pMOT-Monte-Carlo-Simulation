# mot_strange notebooks

These notebooks belong to the conventional multilevel MOT evaluated with the
intensity-derived, pMOT-shaped surrogate magnetic field, together with retained
provisional diagnostics from before the branch split.

The primary comparison notebook is `mot_strange_trajectory_lab.ipynb`. These
notebooks are not the effective two-level pMOT in `notebooks/pMOT_2Level` and
are not the future physical multilevel pMOT reserved under
`notebooks/pMOT_multilevel`.
