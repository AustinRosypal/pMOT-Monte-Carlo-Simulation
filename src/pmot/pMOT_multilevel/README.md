# pMOT_multilevel

This package is reserved for the future physical, hyperfine-resolved
multilevel pseudo-MOT.

It is intentionally a placeholder. Do not copy the `mot_strange` surrogate
magnetic-field construction or the effective `pMOT_2Level` closure here as a
substitute for the required state-resolved Stark Hamiltonian. Implementation
begins only after the conventional two-level and replacement multilevel MOT
validation gates, trapping-light geometry checks, and AC-Stark physics design
are complete.
